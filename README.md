# 词库编辑器 · 1.7.3

打开就能浏览七本内置词库。挑一本合用的，直接导出到输入法；想改几个词，可以就地编辑，也可以导入或新建自己的词库。原始词库由 **天妅** 整理与分享；[词库来源](docs/词库来源.md) 和 [数量说明](docs/词库数量说明.md) 随源码和本地版保留。

**本地使用：** 下载 `ime-dictionary-exporter-offline-1.7.3.zip`，完整解压，用浏览器打开 **`打开词库.html`**。不需要安装软件、启动服务或联网。

**更新已有 GitHub 项目：** 下载 `ime-dictionary-exporter-source-1.7.3.zip`，解压后的 `package.json`、`src/`、`.github/` 等直接对应原仓库根目录。保留本地仓库的 `.git/`，将解压内容覆盖进去，确认差异后按原流程提交。[替换与构建步骤](docs/替换现有仓库.md)

## 浏览、修改和导出

- 在左侧目录选词库；窄屏点当前名称旁的「切换词库」。词表上方可搜索词语或输入码，默认每页 10 词。
- 单击复选框或词条格选中，双击词语或输入码就地编辑；触屏可点行末「编辑」。在页脚调节整张表的宽度，拖动表头分隔线可调列宽。
- 右侧「同码查询」可以输入完整编码，也可单击词表中的输入码标签。它只看当前词库；上下箭头会调整并保存本库的优先级。窄屏从词表工具区打开。
- 点「导出这本词库」，选择目标输入法，核对可导出数量再下载。只导出部分词条时先勾选，再点「批量操作 → 导出已选词条」。可选微软拼音、电脑搜狗、QQ 拼音、苹果文本替换、手机搜狗、讯飞和 Gboard。
- 顶栏「使用指北」有常用操作说明。「重播使用指北」可重新查看分步演示。[完整使用说明](docs/使用说明.md)

## 保存与迁移

修改保存在当前浏览器。在线版和本地 HTML 的数据不会自动互通。如果在旧版或试用网页里改过词库，迁移前先从「设置 → 备份与恢复」下载完整 JSON。在新位置查看现有数据；需要迁移时，从同一处恢复备份，核对数量后确认。恢复会替换目标位置的全部词库。

## 从源码构建

使用 Node.js 22 或以上版本，在本目录执行：

```sh
npm ci
npm run release
```

第一次安装依赖需要联网。构建会做类型检查、运行测试，并生成可直接打开的 `dist/index.html` 和 `release/` 中的离线包、源码包与 Pages 静态包。沿用原仓库的 GitHub Actions 工作流；[开发与构建](docs/开发与构建.md) · [GitHub Pages](docs/GitHubPages发布教程.md) · [1.7.3 更新说明](docs/1.7.3更新说明.md)。
