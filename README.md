# 多平台输入法自定义词库导出器

## 词库来源

原始词库来自**「天妅」** ，感谢原词库作者的整理与分享！

本项目负责词库编辑工具及格式适配，不将原词库署名为本项目原创。来源文件及整理规则见 [词库来源](docs/词库来源.md)。

## 简介

可本地使用的词库编辑工具，支持自由增删词条、调整候选顺序，并导出适用于不同输入法的文件。

英文名称：**Multi-platform IME Custom Dictionary Exporter**（`ime-dictionary-exporter`）。

**下载、解压、打开即可使用。无需登录，无需安装开发工具，编辑和导出不需要联网。**

## 打开工具

打开维护者提供的工具网址即可使用，Mac 与 Windows 用户均可通过浏览器编辑和导出。也可以下载使用包，在本机打开：

### 下载与打开

1. 进入本仓库的 **Releases（发行版）** 页面。
2. 下载发行说明中标注的**使用包 ZIP**，其中包含 `打开词库.html`。
3. 完整解压，用较新的 Edge、Chrome 或 Firefox 打开 **`打开词库.html`**。

编辑词库请选择使用包；GitHub 自动生成的 `Source code` 下载项需要自行构建，不能直接打开使用。

## 可以做什么

- 新增、修改、删除词条，也可以从表格批量添加。
- 按文字或输入码搜索，也可筛选有关联标记的词条。
- 手动标记同义、近义和异体字，查看及管理关联词。
- 设置优先级，调整同一输入码下的候选顺序。
- 暂时停用词条，之后可重新启用。
- 新建自己的词库，或从附带的七个方案开始编辑。
- 拖动排列词库方案，或删除不需要的整个方案。
- 导出输入法文件，以及用于保存完整编辑结果的 JSON 备份。

各词库方案独立维护，在一个方案中修改词条不会自动修改其他方案。

## 管理词库方案

双击方案名称可重命名；也可用 Tab 聚焦名称后按 F2。回车或点击别处保存，Esc 取消。修改名称不改变方案内容及导出格式。

拖动方案左侧的手柄调整顺序，松开后自动保存；也可以用 Tab 聚焦手柄，再按方向键移动。手机窄屏中，方案横向排列，可以左右拖动。

点击方案旁的垃圾桶按钮，核对名称和记录数后确认删除。删除会移除这个方案及其中全部词条，其他方案不受影响；确认窗口可先下载完整备份。至少保留一个方案，最后一个方案的删除按钮会禁用。

## 编辑词条

双击列表中的输入码或优先级即可原处修改，回车或点击别处保存，Esc 取消；键盘聚焦后也可按 F2。输入码使用小写字母或数字，优先级为 1–99 的整数；保存失败会保留填写内容并显示原因。点击词条或右侧铅笔仍可编辑完整记录。

鼠标停在「词条」「输入码」「优先级」「启用」表头上可查看说明，键盘聚焦表头也会显示。

选择左侧词库，点击 **新增词条**，填写：

| 项目 | 含义 | 示例 |
|---|---|---|
| 词条 | 希望输入的文字 | 媎妹 |
| 输入码 | 在输入法中键入的字母 | jiemei |
| 优先级 | 数字越小越优先 | 1 |
| 启用 | 是否加入导出文件 | 勾选 |

同一个输入码可以对应多个候选，例如 `jiemei` 对应“媎妹”和“姐妹”。点击输入码，在候选面板中上下移动，即可重新排列这一组。

**停用会保留记录，删除会移除记录。**

批量添加时，可以从表格复制“输入码、词条、优先级”三列；列之间用 Tab 分隔，每行一条。优先级可省略，省略时设为 1；完全相同的输入码和词条会跳过。

## 筛选含女部件的词条

点击搜索框旁的「含女部」，列出当前词库中至少一个字含女部件的词条，包括「女」本身，以及「安、怒」等内部含女的字。可叠加文字、输入码搜索和启用状态等筛选；再次点击关闭。

筛选只改变列表显示，不修改词条，也不会自动缩小导出范围。若只想导出部分词条，先勾选，再在导出窗口选择选中项。页面数量仍按记录计数，同一词语的不同输入码会分别列出。

按字形匹配，不按含义判断；「母、雌、玅」不会因为性别含义或替换关系而自动匹配。新增词条也可使用此筛选；极少见字或不同地区字形可能存在遗漏。切换词库或刷新页面后筛选关闭。

## 手动标记关联词

在词条旁点击链条图标，选择要关联的词语及「同义」「近义」或「异体字」，点击「保存标记」。也可以先勾选多个词条，再点击上方的「标记关系」。每组选择 2–100 个不同词语，含义由使用者自行判断。

保存后，词语下方会显示标签；点击标签或链条图标可查看、编辑和移除标记。点击关联词可在词库中查找，筛选菜单可选择「有关联标记」。移除标记不会删除词条，也不会改变候选顺序。

标记只在当前词库方案内生效。同一词语的多个输入码共用标记；各组独立保存，不会因为两个词分别关联到第三个词，就自动把它们关联起来。

修改词语写法时，若已没有其他记录使用旧写法，标记会跟随改名；否则仍保留在旧词语上。删除最后一条同词语记录时会将它移出关联组，不足两个词语的组自动移除。停用词条不移除标记。

完整 JSON 备份保留全部标记，旧版备份也能在本工具中恢复。**含标记的备份请使用 1.4.0 或更新版本恢复，旧版工具不识别标记。** 输入法文件只包含原有词条及排名；导出包内的 JSON 备份保留导出范围内有效的标记，缺少至少两个关联词的组不保留。

## 导出到输入法

点击 **导出输入法包**，选择目标输入法和导出范围，查看格式说明及未导出项，然后下载 ZIP。解压后按包内说明操作。

| 目标输入法 | 导出的文件 | 需要了解的区别 |
|---|---|---|
| 微软拼音（Windows） | `.dat` | 保存自定义短语及候选位置；已有导入成功反馈 |
| 搜狗输入法（电脑） | `.txt` | 用于自定义短语配置 |
| QQ 拼音（电脑） | `.ini` | 用于自定义短语导入 |
| 苹果文本替换（macOS） | `.plist` | 同一输入码只导出优先级最高的一条 |
| 搜狗输入法（手机） | `.csv` | 不含独立排名字段；超过 500 条会分包 |
| 讯飞输入法（手机） | `user_dict.txt` | 只保存词语，不保留自定义输入码或排名 |

导出包还会附带导入说明、当前导出范围的词库备份，以及需要另行处理的记录清单。它不包含输入法软件，也不会自动安装。

不同输入法对输入码、长度、生僻字和候选位置的限制不同，具体以导出窗口提示为准。微软已有真实导入反馈，其余格式仍需在对应设备上试导入。

## 保存、备份与恢复

**“已保存到本机”表示保存到了当前浏览器，不等于保存成了电脑文件。**

修改、方案顺序和删除结果会自动保存在本机浏览器中，词库不会上传，也不会跨设备同步。点击顶部 **备份 JSON**，可以下载所有词库的完整备份。

在以下操作前，请先下载完整备份：换浏览器、换电脑、清理浏览器数据、移动 HTML 文件或更新工具。

恢复步骤：**批量添加 → 从 JSON 备份恢复 → 核对数量 → 确认替换**。恢复会替换当前全部词库。

网址与本地 HTML 各自保存数据，切换使用位置时请通过 JSON 备份恢复；浏览器换到新网址、仓库路径或域名时也需要迁移。

如果页面提示“临时会话”，说明浏览器未能开启本地存储。此时仍能编辑、导出，但关闭前需要下载 JSON 才能保留修改。

## 为什么各词库数量不同？

左侧数字与 **记录数** 按“输入码＋词条”计数；**词语数** 只按文字去重。例如，“母父”同时配置 `fumu` 和 `mufu`，算两条记录、一个词语。

七个原文件的收录内容本身也有差异。整理时只合并了各方案内完全相同的记录，没有统一补齐不同方案。详细数据见 [词库数量说明](docs/词库数量说明.md)。

## 显示模式

点击页面顶部的「设置」，选择「白天」「夜晚」或「跟随系统」。选择会保存在当前浏览器中；跟随系统时，页面会随系统外观自动切换。显示偏好不包含在词库 JSON 备份中，清除词库数据时会保留。

## 清除数据与移除

打开 **设置 → 清除数据**，按提示备份并确认。清除成功后可关闭网页、删除本地使用包文件夹。清除作用于当前页面使用的词库存储；已下载的备份和输入法文件需自行删除。

刷新不会自动重建已清除的本地词库，只有点击“重新打开默认词库”才会重新启用。清除后仅保留不含词库内容的状态标记，防止旧窗口将内容写回；临时会话只清理当前内存。

本地使用包仅包含 **打开词库.html**。使用说明、数量说明、词库来源及完整许可文本均整合在网页的 **使用指南** 中。

## 常见问题

**源码包和使用包有什么关系？** 使用包由源码构建生成，界面、样式、程序逻辑和预置词库合并在一个 HTML 文件中。编辑和导出词库只需使用包；修改程序后，需要从源码重新构建。两者不会自动同步修改，词库数据通过 JSON 备份迁移。

**网页打不开或显示空白？** 先确认已完整解压，再用浏览器打开 HTML 文件，避免在压缩软件的预览窗口中使用。

**更新后怎样保留词库？** 旧版下载完整 JSON → 解压新版 → 打开新版 → 从 JSON 恢复。

**为什么导出的条数少了？** 停用记录不参与导出；同码冲突、排名上限或目标格式限制也可能减少数量。查看导出窗口及包内“未导出词条”清单。

**提示在另一个窗口更新？** 刷新当前窗口后重试，避免两个窗口的修改互相覆盖。
