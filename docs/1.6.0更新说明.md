# 1.6.0 更新说明

本版基于 1.5.2，主要改进多输入码词语的编辑体验。

- 同字词合并显示，输入码纵向排列；每个输入码保留独立优先级及启用状态。
- 点击词语集中编辑全部输入码，可增删输入码、修改写法并一次保存。
- 关联标记独立成列：有标记时显示标签，无标记时显示链条按钮。
- 关联窗口新增自定义标签，支持给 1–100 个词语打标签，可修改名称、调整成员、移除标记。
- 区分删除单个输入码与删除整个词语，确认窗口明确显示范围。
- 兼容旧词库和旧 JSON 备份；自定义标签随完整备份和有效范围的导出备份保存，不写入输入法原生文件。

## 更新与迁移

先在旧版点击「备份 JSON」，再打开新版并通过「批量添加 → 从 JSON 备份恢复」导入。网页与本地 HTML 的词库数据不互通，迁移时也使用 JSON。

含自定义标签的 JSON 使用 version 3，需要 1.6.0 或更新版本恢复；不含自定义标签时仍使用 version 2。列表每页按词语分页，顶部记录数仍按输入码＋词语计数。
