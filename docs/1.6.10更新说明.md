# 1.6.10 更新说明

## 界面与操作

- 恢复初版的浅色背景与绿色点缀，保留浅绿顶栏，收紧顶栏下方、标题及编辑卡片上部的间距。
- 右侧编辑卡片常驻，与词条表并排；卡片只有描边，没有阴影。未选词条时显示空白字段、三个页签和不可用的编辑按钮，底部提示「未选择词条」。
- 点击词条或新增词条后，在同一张卡片内编辑，表格与卡片宽度保持稳定。窄屏下卡片移到表格下方，进入编辑时自动滚动到卡片。
- 「输入码／关联标记／候选排序」仍共用草稿，统一保存。结束编辑、切换词条、切换词库或进行其他词库修改前，如有未保存内容，会提供继续编辑或放弃修改的选择。
- 右上角保留保存状态和设置；「备份与恢复」移入设置，适用于全部词库。批量添加、导出当前词库等常用入口继续直接显示。
- 保留词条「启／禁」小标签、输入码状态圆点、关联词查看和标记管理。

## 更新方式

先在旧版下载完整 JSON 备份，再解压新版并打开「打开词库.html」。如果新版未显示原有数据，点击右上角「设置 → 备份与恢复 → 从 JSON 备份恢复」。恢复前核对备份中的数量，再确认替换。

本次不更改词库与备份格式。不同文件路径、网址或浏览器的本地存储可能独立，通过完整 JSON 备份迁移。
