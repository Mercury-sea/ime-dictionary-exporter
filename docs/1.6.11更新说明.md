# 1.6.11 更新说明

## 列表布局与颜色

- 收紧选择框与词条之间的空白，固定两侧选择与删除列的宽度，其余列按比例分配。
- 选择框、词条、关联标记及逐词删除按钮在整行内上下居中；多个输入码与优先级继续逐条对齐。
- 选中后展开的操作栏、表头和选中行使用深、中、浅三档底色；夜晚模式同步调整。

## 选择与编辑

- 勾选词条会同步载入右侧编辑卡片；多选时显示最近勾选的词条。取消当前词条的勾选后，卡片回到其余选择中最近勾选的一条；取消全部选择后显示空白卡片。
- 有未保存草稿时，切换词条或取消全部选择会先询问。选择继续编辑，草稿与原勾选状态都保留；放弃修改后再完成切换。
- 勾选过的词条保存后继续显示在卡片内，新输入码也纳入整词选择。
- 勾选时保留列表焦点，方便连续多选；窄屏下点击词条文字仍可前往编辑卡片。

## 删除确认

- 操作栏中的「删除词条」更名为「批量删除」；每行末尾恢复独立的垃圾桶按钮。
- 两种入口均先显示确认窗口，说明将删除的词条和输入码数量，包含当前筛选未显示的输入码。单条删除不影响其他勾选项，批量删除作用于全部勾选词条。
- 取消删除保留当前数据、选择和编辑草稿；有草稿时，窗口明确说明确认删除也会放弃未保存的修改。
- 删除成功后清理对应关联标记，并保留其他词语之间仍有效的关系。写入失败时保持原数据，允许在确认窗口重试。

## 更新方式

先在旧版下载完整 JSON 备份，再解压新版并打开「打开词库.html」。如需迁移数据，使用右上角「设置 → 备份与恢复 → 从 JSON 备份恢复」。本次没有更改备份格式。
