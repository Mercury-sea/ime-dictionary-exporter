# 1.6.12 更新说明

## 分页和编辑体验

- 页脚可选择每页 10、20、30、50、100 个词语，默认 30，浏览器会记住选择。切换数量时保持原页首词语所在的位置；搜索与筛选仍从第一页开始。
- 放大侧边编辑卡片的输入框、正文、按钮与辅助说明：输入框和主要按钮为 14px，辅助说明为 13px；设置内的说明文字同步增大。
- 点击词条所在行的空白处切换选择，并同步编辑卡片；连续点击可多选。词条文字、关联标签、启禁和删除按钮继续执行各自操作。拖选文字用于复制时不切换选择。
- 未保存草稿的保护继续生效：选择继续编辑时保留原内容及选中状态。

## 新建词库模板

- 新建时可选择全拼、双拼、五笔、自定义模板及默认导出格式；在「词库操作 ⋯ → 输入模板」中也可调整已有词库。
- 全拼支持小写字母、数字与英文单引号；双拼额外支持英文分号，不强制每条编码只能为两个字符；五笔模板检查 a–y 的一至四码。自定义模板支持大小写、符号、空格和其他文字，禁止换行、Tab 及控制字符。
- 模板提供输入规则和示例，不自动将全拼转换为双拼或五笔，也不向空白词库添加示例词条。具体键位按所用双拼方案或五笔版本填写；扩展编码使用自定义模板。
- 切换模板前检查现有编码，不兼容时不改变原数据。导出格式仍有各自的输入限制，导出窗口会列出不兼容项。

## Android Gboard 个人字典

- 「导出当前词库」新增 Gboard，生成根目录含 dictionary.txt 的 PersonalDictionary.zip，可直接交给 Gboard 导入，无需解压。
- 可保留原语言，或统一指定简体中文、繁体中文、英语、所有语言；没有原语言信息的新词条默认使用简体中文。
- 「批量添加 → Gboard 文件」读取个人字典 ZIP 或 dictionary.txt。先预览，再合并到当前词库；同码同词不会重复新增，语言与词性信息合并保留，不覆盖原有启禁、优先级和关联。
- 支持 version 1／2、无快捷码词条、符号及多语言数据。文件与解压文本限制 8 MB，一次最多 10,000 条，并受本工具总容量限制；不读取 Gboard 的内部二进制学习词库。
- Gboard 格式没有本工具的候选优先级、启禁状态与关联标记。只导出启用项，候选显示顺序由 Gboard 决定；完整编辑数据请另下载 JSON 备份。
- 已通过文本、ZIP、备份、浏览器导入和下载验证；尚未完成 Android Gboard 真机导入验收。

## 备份与升级

新版继续恢复 version 1／2／3 备份。含输入模板、扩展输入码或 Gboard 信息时输出 version 4，需要 1.6.12 或更新版本恢复。每页数量属于浏览器显示偏好，不包含在词库 JSON 中。

旧版先下载完整 JSON 备份，再打开新版；需要迁移时，在「设置 → 备份与恢复」中恢复。

## 格式参考

- Gboard v2 格式与实际个人字典文件：[NatoBoram/PersonalDictionary](https://github.com/NatoBoram/PersonalDictionary)。本工具独立实现读取及生成逻辑，没有复制其词库。
- Android 简体中文个人字典导入路径：[yjyao/gboard-flypy](https://github.com/yjyao/gboard-flypy)。
- 双拼编码与分号示例：[Rime 双拼方案](https://github.com/rime/rime-double-pinyin/blob/master/double_pinyin_mspy.schema.yaml)。
- 五笔方案与编码边界参考：[Rime 五笔](https://github.com/rime/rime-wubi)。
