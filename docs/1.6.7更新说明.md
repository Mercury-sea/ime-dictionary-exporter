# 1.6.7 更新说明

- 「启 / 禁」改为小角标：可见外框 12×12px、文字 8px、圆角 2px，整体低于词条字形高度；透明点击范围保留 24×28px。列表与词条编辑窗口使用相同样式。
- 将多码排列与筛选提示移到「词条管理」标题和数量之后，以小号灰字显示；窄屏自动换行，表格底部不再重复提示。
- 输入码圆点单击切换对应码状态，双击打开完整词条编辑。单击等待约 500ms 区分双击，双击会取消待执行的切换；Enter / 空格立即切换，F2 打开编辑。
- 词条编辑窗口为每个输入码增加独立的启用 / 禁用开关，保存后生效，取消可放弃草稿。
- 整词「启 / 禁」仍统一控制全部输入码。至少一个码启用时显示「启」，全部禁用时显示「禁」；各码状态独立保留，导出仍按各码状态处理。
- 保留整行选中效果、首行对齐、红绿圆点、禁用删除线与灰底优先级、紧凑操作栏及展开动画。
