# 1.6.8 更新说明

- 关联标记显示具体对象，例如「同义 · 姐妹」。同类直接关联目标合并，显示前两个及「+N」，悬停查看完整列表；不同关系分行，自定义标签只显示名称，不推断跨组关系。
- 「启 / 禁」可见外框调整为 14×12px、文字为 10px，保留 2px 圆角和 24×28px 透明点击范围，仍低于词条字形高度。启用为绿字浅绿底，禁用为红字浅红底。
- 表头、关联标记、输入码圆点及词条状态使用约 150ms 的悬停提示；词条状态提示为「词条已启用 / 词条已禁用」。键盘聚焦也可查看。
- 全部输入码禁用时，词条文字增加删除线；混合状态只给禁用码加删除线。
- 切换词条及输入码状态继续使用保存锁，但不再让全页按钮短暂变淡；点击圆点不再跳转候选高亮。保存超过 200ms 时才显示进度，失败保留原数据。
- 标记管理的「查看全部标记」内增加「清除当前词库全部标记」，包含自定义标签，可撤销最近一次清除。关闭管理窗口不影响撤销；刷新或关闭网页后撤销记录失效。撤销保留新增标记，只恢复仍有效的关系。
- 四列表头与对应内容按共同中心排列，输入码内部继续按首字母对齐；词条和标记仍对齐首个输入码。

更新前请先在旧版下载完整 JSON 备份；如新版未显示原有数据，可通过「批量添加 → 从 JSON 备份恢复」导入。
