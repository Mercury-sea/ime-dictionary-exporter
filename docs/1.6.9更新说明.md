# 1.6.9 更新说明

## 界面与操作

- 采用确认的灰绿配色：主页面、侧栏和编辑面板分层，输入框为暖白色，底部保存区稍深；夜晚模式同步适配。
- 点击词条打开右侧统一编辑面板，分为「输入码／关联标记／候选排序」三个页签。切换页签保留修改，最后统一保存；取消或关闭时可放弃全部草稿。
- 宽屏为编辑面板预留空间，窄屏使用侧边覆盖面板，手机上铺满屏幕；输入内容可滚动，保存按钮固定在底部。页签支持方向键、Home 与 End；减少动态效果设置有效。
- 输入码圆点单击立即切换状态，不再承担双击编辑；修改输入码和优先级统一从词条编辑面板进入。词条后的微型「启／禁」保留。
- 只给勾选的词条显示整行绿色；编辑中的词条只加局部下划线。词条与关联标记保持首个输入码对齐。
- 主表关系标签显示类型及直接关联词数量，点击后在上方小框中查看纯词语列表。自定义标签仍显示名称。
- 关联标记在统一面板内编辑。移除当前词条的标记会保留其他词语之间仍有效的关系；批量管理中的移除仍作用于整组。
- 候选栏不再常驻。候选排序进入统一面板；重排涉及的其他同码词条与当前词条、关联修改在一次保存中提交，取消不会保存部分内容。
- 备份与恢复移到顶部，明确作用于全部词库；导出按钮标为「导出当前词库」。搜索筛选栏右侧「⋯」提供管理全部标记、清除当前词库全部标记与撤销入口。

## 修正

- 恢复自定义词库后刷新页面，会同步选中实际载入的方案，避免启停按钮因旧方案编号而无响应。
- 保存前统一验证词条改名、输入码重复、优先级与关联标记，错误时保留全部草稿。
- 保留格式元数据、隐藏输入码、旧备份兼容性，以及六种输入法文件的导出规则。

## 更新方式

先在旧版下载完整 JSON 备份，再解压新版并打开「打开词库.html」。如未显示原有数据，使用新版顶部「备份与恢复 → 从 JSON 备份恢复」。不同路径或浏览器的本地存储可能独立。

首次访问引导仍待后续设计，本版先完成已确认的操作结构。
