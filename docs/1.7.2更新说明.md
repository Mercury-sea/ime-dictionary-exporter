# 1.7.2 更新说明

- 词表只接受勾选框和词条格的选中动作；双击词条或码可直接编辑。输入码恢复横排标签，各自携带优先级，停用码带删除线。
- 「词条状态」独立于单码开关。停用整词时不改变内部设置。本机保存和完整备份均保留两层状态。旧备份可直接恢复。
- 编辑和新增使用同一个窗口；新增时查重，发现同名词可打开原词条。鼠标点击和键盘操作均为 ↑ 数字减一、↓ 数字加一。
- 表外留白、筛选区着色；压低搜索框和筛选框，加粗标签。同码、含女字部件两个条件紧贴搜索框，可独立开关。
- 批量启停、标记关联和删除集中在「批量操作」。行末只留「编辑」。「词库管理」集中提供改名、删除、调整顺序、修改模板、同码优先级和关联标记。
- 分步引导可跳过或重看。「使用指北」只保留重播入口；完整备份在「设置 → 备份与恢复」。
