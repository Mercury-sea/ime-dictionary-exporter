# 1.7.3 · 词库目录与同码查询

- 打开即展示当前词库。左侧目录可直接切换，也可以按类别查找或进入词库管理。右侧只查询当前词库的精确输入码，输入或单击词表里的标签即可查看；同码词可用箭头重新排序。
- 两侧可分别收起。空间不足时，仍可从「切换词库」和「同码查询」打开相应功能。主表的搜索、选择、双击编辑和独立的宽度设置照常使用。
- 词表宽度、列宽和收起状态保存在当前浏览器。默认每页 10 个词，可在页脚更改。
- 「使用指北」简要说明查词、编辑与导出；居中的「重播使用指北」从第一步开始。
- 本地与 GitHub Pages 继续使用各自原有的词库存储位置。既有备份可在设置中恢复。原有七本词库的收录和署名保持不变。
