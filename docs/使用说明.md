# 多平台输入法自定义词库导出器：使用说明

打开工具网址，或解压使用包后用浏览器打开「打开词库.html」。无需登录或安装开发工具；本地 HTML 可断网使用。

## 词库方案

双击方案名称可重命名；也可用 Tab 聚焦名称后按 F2。回车或点击别处保存，Esc 取消。修改名称不改变方案内容及导出格式。

拖动方案左侧手柄排序，松开后自动保存；也可聚焦手柄后用方向键移动。窄屏下方案横向排列，支持触摸拖动。

点击垃圾桶按钮删除整个方案，确认窗口会显示名称和记录数，也可先下载完整备份。删除当前方案后会切换到相邻方案；至少保留一个方案。

## 编辑与导出

双击列表中的输入码或优先级即可原处修改，回车或点击别处保存，Esc 取消；键盘聚焦后也可按 F2。输入码使用小写字母或数字，优先级为 1–99 的整数；保存失败会保留填写内容并显示原因。点击词条或右侧铅笔仍可编辑完整记录。

鼠标停在「词条」「输入码」「优先级」「启用」表头上可查看说明，键盘聚焦表头也会显示。

选择左侧方案；点击新增词条，填写输入码、词条、优先级；数字越小越优先。同码候选也可用上下箭头调整。停用的记录会保留在词库中，不加入输入法包。

左侧数字及「记录数」按输入码＋词条计数，同一个词的多个输入码算多条记录。「词语数」只按文字去重。

点击「导出输入法包」，选择目标输入法与导出范围，检查未导出清单后下载 ZIP。解压得到真实输入法文件、导入说明、JSON 备份。并非所有输入法都能保存相同的排名规则：苹果同码仅保留第一候选；讯飞不保存输入码和排名；搜狗手机 CSV 只按文件顺序排列。

## 筛选含女部件的词条

点击搜索框旁的「含女部」，列出当前词库中至少一个字含女部件的词条，包括「女」本身，以及「安、怒」等内部含女的字。可叠加文字、输入码搜索和启用状态等筛选；再次点击关闭。

筛选只改变列表显示，不修改词条，也不会自动缩小导出范围。若只想导出部分词条，先勾选，再在导出窗口选择选中项。页面数量仍按记录计数，同一词语的不同输入码会分别列出。

按字形匹配，不按含义判断；「母、雌、玅」不会因为性别含义或替换关系而自动匹配。新增词条也可使用此筛选；极少见字或不同地区字形可能存在遗漏。切换词库或刷新页面后筛选关闭。

## 手动标记关联词

点击词条旁的链条图标，或先勾选多个词条再点击「标记关系」。在弹窗中选择「同义」「近义」「异体字」，选出 2–100 个不同词语后保存。可按词语或输入码搜索要关联的内容。

词语下方的标签可点击查看；在关联窗口中可以编辑或移除标记，点击关联词可在词库中查找。「有关联标记」筛选只显示已经标记的词条。移除标记不删除词条，标记不改变候选顺序。

各词库方案独立标记，同一词语的多个输入码共用标记。不会自动判断含义，也不会把不同关联组合并。删除某词语的最后一条记录时会清理它的标记；关联组少于两个词语时自动移除。改名时，若没有其他记录使用旧写法，标记会跟随改名；停用则保留标记。

完整 JSON 备份保存所有标记。旧备份仍能恢复；含标记的新备份请用 1.4.0 或更新版本恢复，旧版不识别这些标记。输入法本身不接收标记；导出包内的 JSON 备份只保留导出范围内至少两个词语仍在的关联组。

## 本地保存与迁移

「已保存到本机」表示数据写入了当前浏览器存储，不代表已写入磁盘上的 JSON 文件。清理浏览器、换设备、换浏览器、移动／替换 HTML 文件前，点击「备份 JSON」。本机浏览器数据不会同步给其他人。

如果浏览器拒绝本地存储，会出现临时会话提示；此时仍可以编辑和导出，但关闭前必须下载 JSON 才能保留修改。

从备份恢复：批量添加 → 从 JSON 备份恢复 → 核对内容 → 确认替换。恢复会替换当前全部词库，也会恢复备份中的方案顺序。网址和本地 HTML 的存储独立，切换使用位置时通过 JSON 备份迁移。

多个窗口同时编辑时，旧窗口的保存会被拒绝；刷新旧窗口后再编辑。不要清理存储来处理此提示。

## 批量添加

可从表格复制两列或三列：输入码、词条、优先级。列间用 Tab，行间换行。省略优先级时使用 1，完全相同的输入码与词条会跳过。

## 常见问题

- 打开后空白：先确认已解压，并用较新的 Edge、Chrome 或 Firefox 打开 HTML 文件，而非在压缩包预览器内查看。
- 更换位置后记录消失：浏览器可能将新路径视为新存储位置；从之前下载的 JSON 备份恢复。
- 提示保存失败：不要关闭编辑窗口；可先下载已保存部分的 JSON，检查浏览器存储权限和空间后再试。
- 新版本如何升级：旧版下载 JSON → 解压新版 → 打开新版 → 从 JSON 恢复。不要只依赖浏览器自动保留旧数据。
- 为什么不同方案数量不同：在「使用指南 → 数量说明」查看详情。原方案有各自的记录集合，不会自动互相同步。

微软拼音已有真实导入成功反馈。其他格式需用少量记录在对应设备上试导入，具体限制见导出窗口。

## 显示模式

点击页面顶部的「设置」，选择「白天」「夜晚」或「跟随系统」。选择会保存在当前浏览器中；跟随系统时，页面会随系统外观自动切换。显示偏好不包含在词库 JSON 备份中，清除词库数据时会保留。

## 清除数据与移除使用包

打开「设置 → 清除数据」，可先下载完整备份，再确认清除。清除会移除当前页面使用的词库存储中的全部方案、词条和排序。共享这份存储的窗口会受到影响；已下载到电脑的文件需自行删除。

清除成功后可以关闭页面并删除使用包文件夹。本地存储正常时，刷新或再次打开会停留在“词库数据已清除”页面；点击“重新打开默认词库”才会重新载入预置方案，需要恢复原来的修改时再导入 JSON 备份。

清除后仅保留不含词库内容的状态标记，防止旧窗口将已清除的数据重新写回。临时会话只能清除当前内存中的数据，无法删除浏览器未允许本页面访问的存储；关闭后该会话即结束。
