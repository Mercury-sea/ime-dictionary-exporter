# 词库编辑器：使用指北

首次打开时，首页展示内置的「全拼与简码」。左侧目录可以直接切换词库；窄屏点当前词库名旁的「切换词库」。

## 在词表里编辑

只在复选框或「词条」格单击选择。双击词条改名；双击输入码标签修改码、优先级或单码启停。键盘可用空格选择，Enter 或 F2 编辑词条，Esc 取消编辑；触屏可用行末「编辑」。

- 一个输入码一个标签，标签右侧是自己的优先级。↑ 提高优先级（数字减一），↓ 降低优先级（数字加一），1 最高、99 最低。停用码灰显并加删除线。
- 「词条状态」控制整词：停用后所有码都不导出，但各码原有开关会保留。重新启用后，只有原来启用的码参与导出。旧词库中原本全部码都停用的词会显示为停用，个别码不会被自动打开。
- 行末「编辑」可改名、增删输入码、修改标记、切换整词状态或删除整词。新增词条会在当前词库查重；若已有同名词，可直接打开已有词条。删除整词、批量删除和移除单码都需确认。
- 勾选后打开「批量操作」，可标记关联、启用、停用或删除选中词条。默认每页 10 个词，页脚可选 10、20、30、50 或 100，并记住选择。

搜索词语或输入码，结果会随输入更新。「同码词条」和「含女字部件」可以同时使用。搜索、筛选和翻页都不会改变整库导出的范围。点顶栏的「使用指北」，再点「重播使用指北」，可查看分步演示。

点词表底部的「调整宽度」，拖动滑块调整整张表，也可以点「铺满窗口」。要调整某一列，拖动表头分隔线，或按 Tab 聚焦分隔线后用左右方向键微调。浏览器会记住宽度；在同一处点「默认宽度」或「恢复默认列宽」可以分别还原。

## 同码查询

在右侧「同码查询」输入完整的码，或在电脑上单击词表里的输入码标签，可查看当前词库中使用它的所有词条。点上下箭头可调整顺序；同组会从 1 重新编号。查询独立于词表筛选，停用项也可查看。本库的优先级不代表实际输入法里的候选名次。

空间不足时，从词表工具区打开「同码查询」。两栏都可以收起，给中间的词表腾出空间。

## 词库与编码模板

点「新建词库」，输入名称并选择全拼、双拼、五笔或自定义模板。默认导出格式可以稍后再选。示例和优先级说明随选择变化，创建后是空词库。全拼可以另加首字母或自设简码；双拼按正在使用的键位；五笔按所用版本查码。模板不会自动生成编码。要再查这些技巧，可打开「使用指北 → 查看输入码与优先级技巧」。

「词库管理」可以切换、重命名、调整顺序和删除词库。在「当前词库名称」行改名后点「保存名称」。拖动左侧手柄或聚焦后按方向键调整顺序；删除整个词库需要确认，至少保留一个。切换输入模板可用「词库管理 → 输入模板」；已有编码不符合新模板时不会保存变更。未明确设过模板的旧词库沿用原输入规则，内置全拼和小鹤方案仍可按类别查找。

## 标记和优先级

双击「关联标记」格（包括空白的「—」）查看或编辑，也可多选后点「批量操作 → 标记关联」。选择同义、近义或异体字时，每组需要 2–100 个不同词语；自定义标签可选 1–100 个词语，名称为 1–20 个字符。点「保存标记」生效。「词库管理 → 关联标记」支持管理全部标记、清除标记和在本次打开期间撤销清除。JSON 备份会保留标记。

「词库管理 → 同码优先级」可调整本词库中同一个码下各词的优先级。上下移动会按 1、2、3…… 重排并保存。词表显示的数字是你配置的值，不能代表目标键盘导入后的实际名次。

## 导出

点「导出这本词库」，选择目标输入法，核对可导出数量和未导出项。若只需部分词条，先勾选，再点「批量操作 → 导出已选词条」。Gboard 下载的是可直接导入的 PersonalDictionary.zip；其他 ZIP 解压后含输入法文件、说明和当前导出范围的备份。要备份全部词库，从设置下载完整 JSON。

## 本地保存与迁移

「本地保存」表示数据写入了当前浏览器存储，不代表已写入磁盘上的 JSON 文件。清理浏览器、换设备、换浏览器、移动／替换 HTML 文件前，点击「设置 → 备份与恢复 → 下载完整 JSON 备份」。本机浏览器数据不会同步给其他人。

如果浏览器拒绝本地存储，会出现临时会话提示；此时仍可以编辑和导出，但关闭前必须下载 JSON 才能保留修改。

从备份恢复：设置 → 备份与恢复 → 从 JSON 备份恢复 → 核对内容 → 确认替换。恢复会替换当前全部词库，也会恢复备份中的方案顺序。网址和本地 HTML 的存储独立，切换使用位置时通过 JSON 备份迁移。

多个窗口同时编辑时，旧窗口的保存会被拒绝；刷新旧窗口后再编辑。不要清理存储来处理此提示。

## 批量添加

可从表格复制两列或三列：输入码、词条、优先级。列间用 Tab，行间换行。省略优先级时使用 1，完全相同的输入码与词条会跳过。

## Gboard 个人字典

导出：点击「导出这本词库」，目标选「Gboard · Android」，核对范围和词条语言，再下载 PersonalDictionary.zip。在手机 Gboard 设置中进入「字典（或词典）→ 个人字典 → 对应语言 → ⋮ → 导入」，直接选择 ZIP。无需解压，也无需 root。默认保留导入词条的原语言，新建词条使用简体中文；也可统一指定简体中文、繁体中文、英语或所有语言。

导入到本工具：点击「导入词库」，选择 Gboard 导出的个人字典 ZIP 或 dictionary.txt，核对预览，可选「单独打开为新词库」或「并入」当前词库，再确认。同码同词合并语言与词性标记，不覆盖原有启禁、优先级和关联；重复导入不会再新增。导入不替换其它词库。当前模板不接受某些快捷码时，先切换为自定义。

支持 version 1／2 的 UTF-8 字典文本、空快捷码及多个语言；每次文件和解压后的文本均不超过 8 MB，最多 10,000 条记录，并受本工具整体容量限制。二进制学习词库不在此次支持范围内。Gboard 不保存本工具的候选优先级和关联标记，显示顺序由 Gboard 决定；迁移完整编辑数据请使用 JSON 备份。此功能已完成格式与浏览器验证，尚未完成 Android Gboard 真机导入验收。

## 常见问题

- 打开后空白：先确认已解压，并用较新的 Edge、Chrome 或 Firefox 打开 HTML 文件，而非在压缩包预览器内查看。
- 更换位置后记录消失：浏览器可能将新路径视为新存储位置；从之前下载的 JSON 备份恢复。
- 提示保存失败：不要关闭编辑窗口；可先下载已保存部分的 JSON，检查浏览器存储权限和空间后再试。
- 新版本如何升级：旧版下载 JSON → 解压新版 → 打开新版 → 从 JSON 恢复。不要只依赖浏览器自动保留旧数据。
- 为什么不同方案数量不同：在「设置 → 关于词库编辑器 → 词库数量说明」查看详情。原方案有各自的记录集合，不会自动互相同步。

微软拼音已有真实导入成功反馈。其他格式需用少量记录在对应设备上试导入，具体限制见导出窗口。

## 显示模式

点击页面顶部的「设置」，选择「白天」「夜晚」或「跟随系统」。选择会保存在当前浏览器中；跟随系统时，页面会随系统外观自动切换。显示偏好不包含在词库 JSON 备份中，清除词库数据时会保留。

## 清除数据与移除使用包

打开「设置 → 清除数据」，可先下载完整备份，再确认清除。清除会移除当前页面使用的词库存储中的全部方案、词条和排序。共享这份存储的窗口会受到影响；已下载到电脑的文件需自行删除。

清除成功后可以关闭页面并删除使用包文件夹。本地存储正常时，刷新或再次打开会停留在“词库数据已清除”页面；点击“重新打开默认词库”才会重新载入预置方案，需要恢复原来的修改时再导入 JSON 备份。

清除后仅保留不含词库内容的状态标记，防止旧窗口将已清除的数据重新写回。临时会话只能清除当前内存中的数据，无法删除浏览器未允许本页面访问的存储；关闭后该会话即结束。
