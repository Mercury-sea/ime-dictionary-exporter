# 开发与构建

使用 Node.js 22 或以上版本，在包含 `package.json` 的目录运行 `npm ci` 和 `npm run release`。Windows PowerShell 可使用 `npm.cmd`。普通使用者无需安装依赖。

| 产物 | 用途 |
|---|---|
| `dist/index.html` | 可直接打开的单文件网页；程序、样式、预置词库与许可均内嵌 |
| `release/ime-dictionary-exporter-offline-<版本>.zip` | 本地使用，内含「打开词库.html」 |
| `release/ime-dictionary-exporter-source-<版本>.zip` | 完整源码，可覆盖已有仓库根目录 |
| `release/ime-dictionary-exporter-pages-<版本>.zip` | 静态网页及许可文件 |
| `release/SHA256SUMS.txt` | 三个压缩包的 SHA-256 |

`npm run typecheck` 检查类型；`npm test` 运行词库、存储、格式导出、编辑等回归测试；`npm run build` 只生成网页。`.github/workflows/build.yml` 构建发行包，`.github/workflows/pages.yml` 部署到 Pages。

程序入口是 `src/App.tsx`。词表和侧栏见 `GridCells.tsx`、`WorkspaceRails.tsx`，宽度计算在 `src/lib/table-layout.ts`。预置数据为 `src/lib/presets.json`，本地存储与版本校验见 `src/lib/storage.ts`，输入法导出见 `src/lib/export.ts`。

日常构建直接使用已提交的 `female-components.json`。只有更新女部件表时才需要 `scripts/generate-female-components.py` 和对应版本的 BabelStone IDS 源文件；资料说明见 `vendor/babelstone-ids.NOTICE.txt`。
