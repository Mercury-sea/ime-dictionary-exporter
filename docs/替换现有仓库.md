# 更新已有仓库

1. 打开原来的 `Mercury-sea/ime-dictionary-exporter` 本地仓库。先检查 `git status`；如果已有未提交的工作，先保存或提交。
2. 将源码 ZIP 单独解压。把里面的文件和目录（包括 `.github/` 和 `.gitignore`）覆盖到与原来 `package.json` 同一层。压缩包没有外层项目目录，也不含 `.git`。原仓库的 `.git/`、远程地址和提交历史照常保留。
3. 在仓库根目录用 Node.js 22 或以上运行 `npm ci`，然后运行 `npm run release`。Windows PowerShell 也可以用 `npm.cmd ci` 和 `npm.cmd run release`。打开 `dist/index.html` 验证，查看 `git status` 后再提交。使用 GitHub Desktop 可直接在 Changes 里检查并提交。
4. 推送到原来的 `main` 后，已有的 Pages 工作流会验证代码并发布 `dist/`。如果还没启用 Pages，请按仓库的 [Pages 教程](GitHubPages发布教程.md) 配置。无需上传整个源码 ZIP、依赖目录或本机的词库备份。

此包是完整项目，可单独构建。只想使用工具时，下载独立的 offline ZIP。
