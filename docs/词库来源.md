# 词库来源与分发范围

据项目维护者回忆，原始词库来自微博博主 **「能不能发点有用的」**；豆瓣发布此项目之后，原作者与此项目维护者进行了联系，应原作者要求将署名改为**「天妅」**，十分感谢原词库分享者的整理与分享！

预置数据整理自维护者提供的两份文件：

- 苹果macOS输入法-电脑设置好后用爱思助手同步到手机上.zip
- 微软.QQ.搜狗.讯飞输入法-2025.12.21本文字典.rar

全拼与简码使用 QQ 原文件（比同包电脑搜狗原文件多一条记录）；其余方案分别来自对应平台文件。完全相同的输入码＋词条在各自方案内合并，保留首次出现顺序及设置。苹果和手机 CSV 的无排名记录沿原文件顺序确定同码先后；没有自动应用额外术语替换规则。

源码中的 `tests/fixtures/microsoft-original.dat` 是用于核对二进制结构的原始微软文件。原始压缩包及解压密码不随发行包提供。
