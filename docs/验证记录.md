# 1.1.0 验证记录

## 已完成

- TypeScript 类型检查。
- 七个预置方案通过数据校验，数量与数量说明一致。
- 微软原始 DAT 的 383 条记录可按原顺序、元数据逐字节还原。
- 六种输入法导出包的格式、备份、同码排名、排除规则及手机搜狗分包测试。
- IndexedDB 新建、保存、关闭重开、旧版本拒绝、两个实例竞争写入、JSON 恢复、存储不可用及损坏记录保护测试。
- 在 Linux Chromium 实际打开 `file://` HTML，并将浏览器设为断网：新增、刷新后保留、JSON 下载、微软 ZIP 下载、删除、JSON 恢复均完成。
- 对浏览器实际下载的 DAT 重新解析，确认包含此次新增的词条。
- 关闭浏览器后使用同一测试配置重新打开，保存记录仍可读取。
- 1440 像素桌面和 390 像素窄屏中文界面核对，窄屏没有页面整体横向溢出。
- 检查期间页面没有 JavaScript 异常或 HTTP(S) 网络请求；测试浏览器保留正常网页安全校验。
- 发行文件不包含测试用浏览器配置、私人在线词库、原网站登录和数据库配置。

## 验证范围

微软拼音的真实输入法导入成功由使用者反馈，Windows 和输入法具体版本未记录。
离线网页测试使用 Linux Chromium；未逐一实测所有 Windows、macOS、iOS、Android 浏览器或其他输入法客户端。生僻字是否显示还取决于使用者设备上的字体。

本地存储不可用时退回临时会话并明确提示；跨浏览器、文件位置变化和清理浏览数据后的恢复，应以下载的 JSON 备份为准。

## 1.1.1 名称与文档更新

项目包名与下载包前缀统一为 `ime-dictionary-exporter`，英文全称为 Multi-platform IME Custom Dictionary Exporter。上述浏览器交互记录来自此前功能版本，本次没有改动界面交互及导出逻辑。内部数据库标识沿用旧值，兼容原有保存数据。
